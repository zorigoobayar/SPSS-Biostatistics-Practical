
# SPSS Biostatistics Practical

## Сургалтын зорилго
SPSS программ ашиглан биостатистикийн үндсэн шинжилгээг хийх практик чадвар эзэмшүүлэх.

## Практик ажлын агуулга
1. Өгөгдөл боловсруулах, шинэ хувьсагч үүсгэх
2. Тодорхойлох статистик
3. График дүрслэл
4. Таамаглал шалгах
5. Корреляцийн шинжилгээ

## Файлууд
- `exercise ttest and correlation.sav` – SPSS өгөгдлийн файл
- `SPSS practice ttest & correlation & hypothesis...` – Практик ажлын материал

## Ашиглах заавар
1. Өгөгдлийн файлыг татаж авна.
2. SPSS программд нээнэ.
3. Практик ажлын зааврын дагуу шинжилгээг гүйцэтгэнэ.
